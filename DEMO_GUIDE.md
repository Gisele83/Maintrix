### 2. Diagnostic IA en Action (8 minutes)

#### Scénario A : Moteur Électrique
```
Équipement : Moteur
Zone : Atelier Production
Symptômes : "Vibrations anormales et échauffement"
Urgence : Élevée
```

**À démontrer :**
1. Sélection équipement dans le menu déroulant
2. Saisie symptômes avec autocomplétion intelligente
3. Choix des symptômes cochés (vibrations, température)
4. Activation du mode ML avancé
5. Lancement diagnostic

**Résultats attendus :**
- Diagnostic : Usure roulement
- Confiance : 92%
- Solution détaillée avec étapes
- Estimation coût et durée
- Conseils prédictifs

**Script :**
"L'IA analyse en temps réel les symptômes et compare avec sa base de données de plus de 50 cas réels. Regardez la précision du diagnostic et la richesse des recommandations."

#### Scénario B : Équipement Portuaire
```
Équipement : STS Crane
Zone : Terminal Container
Symptômes : "Problème câble et mouvement erratique"
Mode : Ensemble ML (9 algorithmes)
```

**À montrer :**
- Spécificités équipements portuaires
- Mode Ensemble ML avec consensus
- Métriques avancées (accord modèles, facteur risque)
- Prédictions individuelles des 9 algorithmes

**Script :**
"Voici notre mode le plus avancé : 9 algorithmes ML travaillent ensemble pour un diagnostic ultra-précis. C'est unique sur le marché."
