## 📋 Onglets Smart Diagnostic

### 1. Onglet Diagnostic
- **Formulaire complet** : Sélection équipement, symptômes, urgence
- **Modes ML** : Choix entre Standard, Avancé, Ensemble ML
- **Résultats temps réel** : Suggestions avec scoring confiance
- **Analyse prédictive** : Probabilité défaillance et maintenance

### 2. Onglet Réparation  
- **Procédures guidées** : Instructions étape par étape
- **Sécurité** : Avertissements et précautions
- **Outils requis** : Liste équipements nécessaires
- **Validation** : Confirmation achèvement chaque étape

### 3. Onglet Historique
- **Historique complet** : Tous les diagnostics précédents
- **Filtrage avancé** : Par date, équipement, type, technicien
- **Export données** : CSV/Excel pour analyses
- **Tendances** : Évolution performance diagnostics

### 4. Onglet Rapports
- **Rapports automatiques** : Génération après interventions
- **KPIs maintenance** : MTBF, MTTR, disponibilité
- **Analyses coûts** : Budgets et optimisation
- **Export professionnel** : PDF formatés pour direction

### Workflow Unifié
```
Smart Diagnostic IA → Smart GMAO → IoT Monitoring → Intervention
```

1. **Diagnostic IA** : Page dédiée avec modes ML avancés
