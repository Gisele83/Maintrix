## Onglets Intégrés Smart Diagnostic

### 1. Onglet Diagnostic
**Fonctionnalités :**
- **Sélection Mode ML** : 3 modes disponibles (Standard/Avancé/Ensemble)
- **Formulaire Intelligent** : Adaptation selon type équipement
- **Symptômes Organisés** : Classification par catégories (mécanique, thermique, électrique, fluide, performance, contrôle, environnemental)
- **Scoring Confiance** : Pourcentage de fiabilité des suggestions
- **Analyse Prédictive** : Probabilité défaillance et recommandations

**Équipements Supportés :**
- Moteurs électriques et thermiques
- Pompes hydrauliques et centrifuges
- Compresseurs et turbines
- Transformateurs et convertisseurs
- Électronique de puissance (UPS, onduleurs, rectifieurs)
- Équipements portuaires (grues STS/RTG, reach stackers, spreaders)
- Systèmes HVAC et automation

### 2. Onglet Réparation
**Fonctionnalités :**
- **Procédures Guidées** : Instructions étape par étape illustrées
- **Consignes Sécurité** : Avertissements et précautions obligatoires
- **Outils Requis** : Liste complète équipements et pièces
- **Validation Étapes** : Confirmation progression avec photos
- **Temps Estimé** : Durée prévisionnelle intervention
- **Niveau Compétence** : Classification technicien requis

### 3. Onglet Historique
**Fonctionnalités :**
- **Historique Complet** : Tous diagnostics avec métadonnées
- **Filtrage Avancé** : Par date, équipement, technicien, résultat
- **Recherche Sémantique** : Recherche intelligente dans descriptions
- **Tendances Performance** : Évolution précision diagnostics
- **Export Données** : CSV/Excel pour analyses externes
- **Comparaison Cas** : Analyse cas similaires

### 4. Onglet Rapports
**Fonctionnalités :**
- **Rapports Automatiques** : Génération après chaque intervention
- **KPIs Maintenance** : MTBF, MTTR, disponibilité, coûts
- **Analytics Prédictives** : Tendances et projections
- **Export Professionnel** : PDF formatés pour direction
- **Dashboard Personnalisé** : Métriques selon rôle utilisateur
- **Reporting Périodique** : Rapports automatiques hebdo/mensuel

## Modes ML Avancés

### Mode Standard ML
**Technologies :**
- Random Forest (Forêts Aléatoires)
- Gradient Boosting Classifier
- TF-IDF pour analyse textuelle

**Avantages :**
- Rapidité d'exécution (< 2 secondes)
- Bon équilibre précision/performance
- Fonctionnement offline possible
- Ressources minimales requises

### Mode Avancé ML
**Technologies :**
- Multi-Layer Perceptron (Réseaux Neurones)
- Support Vector Machine (SVM)
- Isolation Forest (Détection Anomalies)
- Principal Component Analysis (PCA)

**Avantages :**
- Précision supérieure (90-95%)
- Détection anomalies complexes
- Analyse patterns subtils
- Apprentissage profond

### Mode Ensemble ML
**Technologies (9 Algorithmes) :**
1. Random Forest
2. Gradient Boosting
3. Support Vector Machine
4. Multi-Layer Perceptron
5. K-Nearest Neighbors
6. Decision Tree
7. Logistic Regression
8. Gaussian Naive Bayes
9. AdaBoost

**Avantages :**
- Précision maximale (95-98%)
- Consensus multi-modèles
- Robustesse exceptionnelle
- Confiance élevée
