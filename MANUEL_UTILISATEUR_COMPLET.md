## Accès à Smart Diagnostic

   - Redirection directe vers l'interface dédiée

   - Sélectionnez "Smart Diagnostic IA"

## Interface Smart Diagnostic

### Page Dédiée avec Onglets
**4 Onglets Intégrés :**
- **Diagnostic** : Formulaire IA et analyse
- **Réparation** : Procédures guidées
- **Historique** : Consultations précédentes
- **Rapports** : Analytics et exports

### Onglet Diagnostic - Utilisation Détaillée

#### Étape 1: Sélection Mode ML
```
○ Standard ML
  • Technologies : Forêts aléatoires + Gradient Boosting
  • Utilisation : Diagnostics routine, rapidité
  • Temps réponse : < 2 secondes
  • Précision : 85-90%

○ Avancé ML  
  • Technologies : Réseaux neurones + SVM + Détection anomalies
  • Utilisation : Cas complexes, analyse poussée
  • Temps réponse : 3-5 secondes
  • Précision : 90-95%

○ Ensemble ML
  • Technologies : Consensus 9 algorithmes
  • Utilisation : Diagnostic critique, validation croisée
  • Temps réponse : 5-10 secondes
  • Précision : 95-98%
```

#### Étape 2: Informations Équipement
**Champs Obligatoires :**
- **Type équipement** : Liste déroulante comprehensive
  - Moteurs électriques/thermiques
  - Pompes hydrauliques/centrifuges
  - Compresseurs/turbines
  - Transformateurs/convertisseurs
  - Électronique puissance (UPS, onduleurs)
  - Équipements portuaires (grues, spreaders)

- **Zone/Secteur** : Localisation physique
  - Production principale
  - Atelier mécanique/électrique
  - Zone logistique/stockage
  - Salle électrique/automation
  - Équipements extérieurs

- **ID Équipement** : Référence unique (optionnel)

#### Étape 3: Sélection Symptômes
**Symptômes Organisés par Catégories :**

**🔧 Mécaniques :**
- Vibrations anormales (faible/moyenne/forte)
- Bruits inhabituels (grincement/claquement/sifflement)
- Désalignement visible
- Usure prématurée composants
- Jeu mécanique excessif

**🌡️ Thermiques :**
- Surchauffe générale/localisée
- Température instable
- Refroidissement insuffisant
- Gradient thermique anormal

**⚡ Électriques :**
- Court-circuit/surintensité
- Chute tension/coupure
- Isolation défaillante
- Harmoniques/perturbations
- Arc électrique

**💧 Fluides :**
- Fuite hydraulique/pneumatique
- Pression anormale (haute/basse)
- Débit réduit/instable
- Contamination fluide
- Température fluide anormale

**📊 Performance :**
- Rendement dégradé
- Arrêt intempestif
- Démarrage difficile
- Régulation défaillante
- Consommation excessive

#### Étape 4: Contexte et Urgence
**Niveau d'Urgence :**
- 🔴 **Critique** : Arrêt production imminent
- 🟡 **Important** : Performance dégradée significative
- 🟢 **Mineur** : Surveillance renforcée nécessaire

**Contexte d'Utilisation :**
- Charge de travail actuelle
- Conditions environnementales
- Historique maintenance récent
- Modifications récentes

#### Étape 5: Lancement et Résultats
1. Cliquez "Lancer le Diagnostic IA"
2. Patientez pendant l'analyse (temps selon mode)
3. Consultez résultats détaillés avec scoring

### Interprétation des Résultats

#### Scoring de Confiance
- **95-100%** 🟢 : Diagnostic très fiable, action immédiate
- **80-94%** 🟡 : Diagnostic probable, vérification recommandée
- **60-79%** 🟠 : Diagnostic possible, investigation approfondie
- **<60%** 🔴 : Analyse incertaine, expertise humaine requise

#### Informations Détaillées
- **Diagnostic Principal** : Cause la plus probable avec explication
- **Diagnostics Alternatifs** : Autres possibilités par ordre de probabilité
- **Recommandations Immédiates** : Actions prioritaires à effectuer
- **Pièces Suggérées** : Liste prévisionnelle besoins
- **Coût Estimé** : Budget prévisionnel intervention
- **Urgence IA** : Évaluation automatique priorité

### Onglet Réparation

#### Procédures Guidées
**Structure Standard :**
1. **Vue d'ensemble** : Description générale intervention
2. **Consignes sécurité** : Précautions obligatoires détaillées
3. **Outils et équipements** : Liste complète matériel requis
4. **Étapes détaillées** : Instructions illustrées pas-à-pas
5. **Points de contrôle** : Validations intermédiaires
6. **Tests finaux** : Vérifications bon fonctionnement

#### Niveaux de Procédures
- **Dépannage Express** : Actions urgentes < 30 min
- **Réparation Standard** : Intervention classique 1-4h
- **Maintenance Approfondie** : Révision complète > 4h
- **Remplacement Majeur** : Changement composant critique

### Onglet Historique

#### Navigation et Filtrage
**Filtres Disponibles :**
- **Période** : Date/heure diagnostic
- **Équipement** : Type ou ID spécifique
- **Technicien** : Personne ayant effectué

- **Résultat** : Confiance ou type diagnostic
- **État** : En cours/Terminé/Archivé

#### Fonctionnalités Avancées
- **Recherche sémantique** : Mots-clés intelligents
- **Comparaison cas** : Analyse similitudes
- **Tendances performance** : Évolution précision
- **Export sélectif** : Données ciblées

### Onglet Rapports

#### Types de Rapports
**Rapport d'Intervention :**
