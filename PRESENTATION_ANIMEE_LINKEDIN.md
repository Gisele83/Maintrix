## 🎬 **EXPORT VIDÉO POWERPOINT**

### **Méthode Simple :**
1. **Fichier → Exporter → Créer une vidéo**
2. **Qualité** : Ultra HD (4K) ou Full HD
3. **Timing** : 5-8 secondes par slide
4. **Transitions** : Automatiques
5. **Format** : MP4

### **Paramètres Optimaux :**
```
Résolution : 1920x1080 (16:9) ou 1080x1080 (1:1)
Frame Rate : 30fps
Bitrate : 8 Mbps
Codec : H.264
Audio : Optionnel (musique background)
Durée : 60-90 secondes
Taille : <4MB (compression LinkedIn)
```
