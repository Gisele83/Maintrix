## 4. TEMPLATE REVENDICATIONS BREVET

### Revendications Indépendantes

#### **Revendication 1 (Système général)**
```
Système de gestion de maintenance industrielle caractérisé en ce qu'il comprend :
- Une interface utilisateur unifiée (100) permettant l'accès simultané à des fonctions de gestion de maintenance assistée par ordinateur (GMAO) et de diagnostic intelligent automatique,
- Un module de diagnostic (200) intégrant un ensemble de neuf algorithmes d'apprentissage automatique fonctionnant en consensus pondéré,
- Une base de données historiques (300) contenant au moins 120 cas de maintenance industrielle authentiques avec leurs résolutions,
- Un moteur d'inférence (400) capable de générer des diagnostics avec un niveau de confiance supérieur à 95%,
- Des moyens de communication (500) permettant la synchronisation de données entre une application mobile et une application web en mode déconnecté.
```

#### **Revendication 2 (Algorithme ensemble)**
```
Procédé de diagnostic automatique d'équipements industriels caractérisé par les étapes suivantes :
- Collecte de données symptômes via interface utilisateur ou capteurs IoT,
- Application parallèle de neuf algorithmes distincts : Random Forest, Gradient Boosting, SVM, MLP, Isolation Forest, Naive Bayes, Decision Tree, K-Means, Régression Logistique,
- Calcul d'un score de consensus pondéré basé sur les performances historiques de chaque algorithme,
- Génération d'un diagnostic final avec niveau de confiance quantifié,
- Apprentissage continu par rétroaction des résultats terrain.
```

### Revendications Dépendantes
```
3. Système selon la revendication 1, caractérisé en ce que l'interface unifiée (100) permet le basculement transparent entre mode GMAO traditionnel et mode diagnostic IA sans perte de contexte utilisateur.

4. Système selon la revendication 1, caractérisé en ce que l'application mobile comprend une base de données locale SQLite synchronisée avec résolution automatique des conflits.

5. Procédé selon la revendication 2, caractérisé en ce que la pondération des algorithmes est ajustée dynamiquement selon le type d'équipement et l'historique des performances.

6. Système selon la revendication 1, caractérisé en ce qu'il comprend des moyens d'import automatique de données Excel avec reconnaissance de schémas multi-tables.
```
