## 2. DÉPÔT DE LOGICIEL ET ŒUVRE (INPI)

### Informations de l'Œuvre
- **Titre de l'œuvre** : Smart GMAO DiagFix - Plateforme Unifiée de Maintenance Intelligente
- **Type d'œuvre** : Programme d'ordinateur (code source et objet) + Documentation technique complète
- **Auteur** : Dr. Gisèle Béatrice Sonfack (auteur unique)
- **Année d'achèvement** : 2025
- **Langage de programmation** : TypeScript, React, Node.js, Python

### Description Technique Détaillée

#### Architecture Logicielle
**Application web unifiée** combinant :
1. **Module GMAO (Gestion de Maintenance Assistée par Ordinateur)**
   - Gestion d'équipements industriels avec base de données enrichie (120 cas réels)
   - Planification de maintenance préventive et corrective
   - Gestion des bons de travail et interventions
   - Système de gestion des stocks et pièces de rechange

2. **Module Diagnostic Intelligent**
   - Moteur IA multi-algorithmes (9 modèles ML en ensemble)
   - Diagnostic automatique basé sur symptômes et données historiques
   - Analyse prédictive des pannes avec confiance à 98%
   - Interface de saisie symptômes intuitive

3. **Application Mobile React Native**
   - Interface terrain pour techniciens
   - Mode hors ligne avec synchronisation
   - Scanner QR pour identification équipements
   - Guidage étape par étape des réparations

#### Innovations Techniques Protégeables
1. **Système d'ensemble ML hybride** : Combinaison de 9 algorithmes différents pour diagnostic consensus
2. **Architecture modulaire unifiée** : Interface unique intégrant GMAO et diagnostic IA
3. **Système d'import Excel intelligent** : Traitement automatique de 6 tables interconnectées
4. **Mode offline-first mobile** : Synchronisation bidirectionnelle avec gestion conflits

#### Base de Code
- **Frontend** : React 18 + TypeScript, Tailwind CSS, shadcn/ui
- **Backend** : Node.js + Express, PostgreSQL + Drizzle ORM
- **IA/ML** : Python avec scikit-learn, ensemble de 9 modèles
- **Mobile** : React Native avec SQLite offline
- **Déploiement** : Docker, scripts automatisés, support multi-plateforme

## 3. DÉPÔT DE BREVET (OPTIONNEL - RECOMMANDÉ)

### Informations du Brevet
- **Titre de l'invention** : Plateforme GMAO augmentée par IA pour diagnostic intelligent et planification prédictive de maintenance industrielle
- **Inventeur** : Dr. Gisèle Béatrice Sonfack
- **Domaine technique** : Maintenance industrielle, Intelligence artificielle, IoT

### Résumé de l'Invention
Système de gestion de maintenance modulaire basé sur le cloud, intégrant des modèles d'apprentissage automatique avancés pour le diagnostic en temps réel, l'analyse prédictive des pannes et la planification automatisée des interventions de maintenance industrielle.

### Revendications Techniques Principales

#### **Revendication 1 - Système intégré**
Système combinant surveillance IoT temps réel, base de données historique de 120 cas industriels authentiques, et moteur d'ensemble ML à 9 algorithmes pour diagnostic automatique avec niveau de confiance supérieur à 95%.

#### **Revendication 2 - Architecture modulaire**
Interface utilisateur unifiée permettant basculement transparent entre module GMAO traditionnel et module diagnostic IA, avec partage de données contextuel et workflow intégré.

#### **Revendication 3 - Moteur de diagnostic ensemble**
Algorithme d'ensemble combinant Random Forest, Gradient Boosting, SVM, réseaux de neurones MLP, détection d'anomalies Isolation Forest, pour consensus multi-modèles avec pondération dynamique.

#### **Revendication 4 - Système d'apprentissage continu**
Mécanisme de feedback utilisateur intégré permettant amélioration continue des modèles avec base de données enrichie automatiquement par retours d'expérience terrain.

#### **Revendication 5 - Architecture offline-first mobile**
Application mobile avec base SQLite locale, synchronisation bidirectionnelle intelligente, et résolution automatique de conflits pour environnements industriels sans connectivité constante.

### Avantages Techniques
- **Performance diagnostique** : 98% de précision sur cas industriels réels
- **Scalabilité** : Architecture modulaire extensible
- **Fiabilité** : Mode dégradé et fonctionnement offline
- **Intégration** : APIs RESTful pour systèmes existants (SAP, Maximo)
